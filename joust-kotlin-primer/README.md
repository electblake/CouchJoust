# Joust V4 Android TV Kotlin build package

Open **`OPEN_ME.html`** for the illustrated guide and browsable graphics/audio catalog.

Give the build agent **`START_HERE.md`** and the complete extracted folder.

- `assets/` — decoded original PNGs, WAVs, pixel/sample data and asset metadata.
- `data/` — exact game, movement, wave, difficulty and text tables.
- `docs/JOUST_GAME_SPEC.md` — complete native gameplay specification, with an HTML reading copy.
- `reference/` — Kotlin helpers and the pinned original source.
- `tools/` — extraction, document and verification utilities.
- `verification/` — checks performed, arithmetic vectors and reproducibility evidence.

Source: `synamaxmusic/joust`, revision `87e22aab945709fa107df609c0efcb839a17c1f9`. See `PROVENANCE.json` and `REPRODUCE.md`.
