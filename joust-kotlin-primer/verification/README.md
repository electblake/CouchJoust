# Verification record

## Performed for this package

- Original source pin and source-file SHA-256 inventory recorded in `PROVENANCE.json`.
- 90 wave records, repeat entry 81, 28 dynamic difficulty records, 69 egg positions and 14 baiter delays extracted and checked. Fresh-directory JSON/CSV regeneration matched byte-for-byte; altered source input was rejected.
- Terrain maps, 13 ground states, nine flight speeds and physics constants regenerated byte-for-byte.
- All 200 individual graphics/font PNGs checked against their exact palette-index grids; 43 collision profiles retained. Both source-image extractors also ran without a system font dependency; the original assets were unchanged.
- Title geometry/raster, terrain reconstruction and explanatory figures visually inspected. Static reconstructions are labeled as such.
- 139 literal phrases, 30 static text pages, 67 positioned entries and 41 default score records decoded, including observed font contexts and additional encoded copyright/credit blocks.
- Original sound program assembled from source and matched the known reference CRC32/SHA1. No sound ROM download was used.
- All 76 WAVs checked for file hash, mono 48 kHz / 16-bit PCM format, length, completion and matching raw sample traces. No audible capture was truncated. All 40 game events are represented, including three control-only events.
- Offline sound execution checks cover the complete command/control sweep and targeted arithmetic, timing and interruption behavior; details are in `assets/audio/tools/offline6800/`.
- Native Kotlin helper formulas reviewed against source. Numeric vectors are supplied in `math-vectors.json`.
- 496 local links in the entry page, game guide and asset catalog resolved. HTML structure was generated and checked; a browser screenshot run was unavailable in this environment. No browser-rendered layout test is claimed.
- Final per-file hashes and ZIP integrity checked before delivery.

## Not claimed

This package does not contain a compiled Kotlin game, an Android APK, a completed source-versus-native replay comparison, a physical arcade recording comparison, or testing on the user's Sony TV. The guide gives concrete acceptance cases for that implementation work. Audio timestamps, analog coloration and cross-event state limits are stated in the audio README; the captures are source-derived reference output.

`package-checks.json` records the final structural/data/asset checks. `FILE_MANIFEST.json` hashes all deliverable files except itself. Run `tools/verify_package.py` after extracting to recheck the package. Editing or regenerating files intentionally changes those hashes.
